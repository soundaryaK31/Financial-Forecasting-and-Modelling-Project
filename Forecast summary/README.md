
# Forecast Summary

## Workbook Contents
This workbook presents a consolidated summary of the five-year financial forecast from FY2026E to FY2030E. It brings the key outputs from the Profit and Loss, Cash Flow and Debt schedules into one review-friendly worksheet.

## Financial Calculations
The summary displays five key metrics for each forecast year:
- Revenue
- Net Profit
- EBITDA Margin %
- Closing Cash
- Closing Debt

The figures are linked to the relevant forecast schedules so the summary reflects the model outputs.

## Formulas and Modelling Techniques
- Cross-sheet cell references to pull forecast outputs into one summary.
- Consistent year-by-year presentation from FY2026E through FY2030E.
- Charts to visualise Revenue and Net Profit, EBITDA Margin %, and Closing Cash and Closing Debt.

## Final Output
The worksheet provides a quick view of projected growth, profitability, liquidity and debt across the five-year forecast period. The charts make it easier to compare trends and review the overall financial outlook.

*This is an educational financial-modelling project. Forecast figures are estimates based on model assumptions, not actual company results.*
