
# Profit and Loss Forecast

## Workbook Contents
This workbook contains the projected Profit and Loss statement for FY2026E to FY2030E. It uses the assumptions prepared in Task 1 to build a five-year view of expected revenue, expenses and profitability.

## Financial Calculations
The forecast calculates projected revenue and operating costs, then derives key profit measures, including EBITDA and Net Profit. It also calculates EBITDA Margin % to show EBITDA in relation to revenue.

## Formulas and Modelling Techniques
- Links to the forecast assumptions rather than duplicating input values.
- Revenue and expense projections using relevant growth rates and operating assumptions.
- Formula-driven subtotals and profit calculations.
- Margin analysis using profitability as a percentage of revenue.

## Final Output
The workbook produces a five-year projected Profit and Loss statement. It demonstrates how operating assumptions translate into forecast revenue, costs and profitability, and provides the earnings forecast used by the cash flow and debt model.

*This is an educational financial-modelling project. Forecast figures are estimates based on model assumptions, not actual company results.*
