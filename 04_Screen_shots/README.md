
# Financial Forecasting Model – Screenshots

This folder contains screenshots of the Excel financial forecasting model developed as part of this project.

## Screenshots Included

### 1. Forecast Assumptions
Screenshots showing the key assumptions and forecast drivers used to prepare the five-year financial model (FY2026E–FY2030E).

### 2. Profit and Loss Forecast
Screenshots displaying projected revenue, expenses and profitability, including key profit measures and EBITDA margin.

### 3. Cash Flow and Debt Forecast
Screenshots illustrating projected cash movements, closing cash balances, debt repayments and closing debt balances.

### 4. Forecast Summary
A consolidated view of the five-year forecast, highlighting Revenue, Net Profit, EBITDA Margin, Closing Cash and Closing Debt through summary tables and charts.

## Purpose

These screenshots provide a visual overview of the completed Excel model, its financial schedules and the key outputs generated through financial forecasting and modelling.
