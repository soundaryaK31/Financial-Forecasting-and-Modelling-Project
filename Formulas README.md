# Financial Modelling Formula Guide

This folder contains the Financial Modeling Formula Guide used as a reference while developing the five-year financial forecasting model.

## Document Included

**Financial Modeling Formula Guide.docx**

## Purpose

The document provides a reference for understanding and applying financial modelling formulas and calculations used in forecasting.

It supports the preparation and review of the following schedules:

- Forecast assumptions
- Revenue and expense projections
- Profit and Loss calculations
- EBITDA and profitability measures
- Cash flow calculations
- Debt schedules and interest expense
- Financial forecast summaries

## Learning Objective

To understand how financial assumptions and Excel formulas are used to prepare structured financial forecasts and connect different financial schedules.

This is an educational reference document associated with the financial forecasting project.
