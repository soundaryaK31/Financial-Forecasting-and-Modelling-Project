# Financial Forecasting and Modelling Project

## Project Overview
This project demonstrates a five-year financial forecasting model developed using Microsoft Excel. It covers financial assumptions, profit and loss forecasting, cash flow forecasting, debt schedules and financial performance summaries.

## Project Objectives
- Build a five-year financial forecast (FY2026E–FY2030E).
- Develop revenue and expense projections.
- Prepare a projected Profit & Loss statement.
- Forecast operating, investing and financing cash flows.
- Develop cash and debt repayment schedules.
- Create a financial forecast summary with charts.

## Project Structure

1. Forecast Assumptions
2. Profit & Loss Forecast
3. Cash Flow and Debt Forecast
4. Forecast Summary and Visualisation

## Tools Used
- Microsoft Excel
- Excel formulas and financial modelling
- Financial forecasting
- Data visualisation

## Key Skills Demonstrated
- Revenue forecasting
- Cost and expense forecasting
- EBITDA and profitability analysis
- Cash flow forecasting
- Debt schedule modelling
- Interest expense calculations
- Financial statement analysis
- Financial dashboard creation

## Project Outcome
Developed an integrated five-year financial forecasting workbook with linked financial statements, cash and debt schedules, and a summary dashboard to support financial planning and analysis.

## Disclaimer
This is an educational financial modelling project. The forecasts are illustrative and should not be interpreted as actual company financial results.
