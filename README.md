# Five-Year Financial Forecasting Model (Excel)

An educational financial modelling project that builds a five-year forecast for FY2026E–FY2030E using Microsoft Excel. The project is organised into linked schedules covering operating assumptions, projected profitability, cash flow, debt and a management summary.

## Project Overview

The model demonstrates how operating and financial assumptions can be translated into forecast revenue, costs, profitability, cash balances and debt movements. The schedules are connected through Excel formulas and cell references so that changes to key inputs can flow into downstream calculations.

**Forecast Period:** FY2026E–FY2030E  
**Tool:** Microsoft Excel  
**Project Type:** Financial Forecasting and Modelling

## Project Objectives

- Organise operating and financial assumptions for a five-year forecast.
- Forecast revenue using product-level volume and pricing drivers.
- Project costs, EBITDA, margins and net profit through a Profit & Loss schedule.
- Prepare cash flow and debt schedules, including cash movements, debt repayments and interest.
- Summarise key forecast outputs using tables and charts.
- Practise formula-based modelling and links between schedules.

## Modelling Methodology

The model follows this workflow:

1. **Assumptions:** Enter operating and financial drivers for the forecast period.
2. **Revenue Forecast:** Calculate product revenue using forecast units sold and average selling prices.
3. **Profit & Loss:** Project revenue, costs and profitability.
4. **Cash Flow and Debt:** Calculate cash movements, debt balances and interest.
5. **Forecast Summary:** Consolidate key outputs for reviewing the five-year forecast.

## Key Outputs

- Revenue
- Net Profit
- EBITDA Margin
- Closing Cash
- Closing Debt

These outputs help review projected growth, profitability, liquidity and debt over FY2026E–FY2030E.

## Important Scope Note

This repository demonstrates a five-year forecast built from assumptions, a Profit & Loss forecast, cash flow and debt schedules, and a summary.

It should not be interpreted as a complete integrated three-statement model because a full projected Balance Sheet is not included in the current repository.

## Disclaimer

This project is for educational and portfolio purposes. Forecasts are illustrative outputs based on workbook assumptions and are not actual company results, investment advice or a guarantee of future performance.
