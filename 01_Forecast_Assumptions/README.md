
# Forecast Assumptions

## Workbook Contents
This workbook contains the key operating and financial assumptions used as inputs for the five-year financial forecast from FY2026E to FY2030E. These assumptions drive the projected financial statements in the later stages of the model.

## Financial Calculations
The assumptions are used to project future business performance, including revenue and expense-related items. They form the basis for calculating forecast values in the Profit and Loss, Cash Flow and Debt schedules.

## Formulas and Modelling Techniques
- Input-driven forecasting using clearly identified assumptions.
- Percentage and growth-rate assumptions to calculate projected values.
- Cell references so downstream schedules can use the assumptions consistently.
- Linked-workbook modelling to avoid re-entering the same assumptions in multiple schedules.

## Final Output
The workbook provides a structured set of forecast drivers for FY2026E–FY2030E. These inputs make the model easier to update and allow changes in assumptions to flow through to subsequent forecast schedules.

*This is an educational financial-modelling project. Forecast figures are estimates based on model assumptions, not actual company results.*
